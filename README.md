# POST — Контентный контур экосистемы NOVA CORTEX / MAIA

> **Протокол бесшовного входа для LLM:**  
> Этот репозиторий — открытое зеркало модуля `POST`. Перед началом работы прочитай документы в строгом порядке:
> 1. `CLAUDE.md` — пайплайн работы и критерии перехода между этапами (Gates).
> 2. `INVARIANTS.md` — неизменяемые правила и барьеры истинности.
> 3. `EDITORIAL_POLICY.md` — фильтр Первого эшелона, голос канала и формат (2 500–4 000 знаков).
> 4. `RUNTIME.md` — текущее состояние контура, очередь и реестр карточек.

## Архитектура и источники истины
`POST` преобразует квалифицированные сигналы из дайджестов `MAYA` в научно-популярные публикации для Telegram-канала.

* **Первичный источник истины:** локальный репозиторий на хосте Архитектора (`POST`).
* **Публичный GitHub:** активное открытое зеркало (`https://github.com/shaenxxx-commits/POST`) для синхронизации контекста и подключения LLM-агентов. Обновляется после проверки на секреты и санкции Архитектора.

## Структура репозитория
* `README.md` — точка входа и навигация для LLM.
* `CLAUDE.md` — операционный регламент и критерии готовности (Gates).
* `INVARIANTS.md` — жёсткие правила работы с данными, доказательствами и текстом.
* `EDITORIAL_POLICY.md` — редакционный стандарт и система триажа по эшелонам.
* `RUNTIME.md` — живое состояние и реестр материалов.
* `templates/record-template.md` — минималистичный шаблон карточки статьи.
* `records/YYYY/` — проработанные карточки (`NNN_<slug>.md`).
* `logs/` — схема событий и append-only журнал (`events.jsonl`).
* `scripts/` — задел под будущие утилиты валидации и автоматизации.
