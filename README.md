# POST — Контентный контур экосистемы NOVA CORTEX / MAIA

> **Инструкция для LLM (протокол бесшовного подхвата):**  
> Этот репозиторий — открытое зеркало контентного модуля `POST`. Если тебе передали ссылку на этот репозиторий для продолжения работы, **обязательно прочитай файлы в следующем порядке**, прежде чем выполнять любые действия:
> 1. `CLAUDE.md` — операционный регламент и пайплайн обработки.
> 2. `INVARIANTS.md` — неизменяемые правила и запреты.
> 3. `EDITORIAL_POLICY.md` — формат, объём (2 500–4 000 знаков) и критерии отбора (Первый эшелон).
> 4. `RUNTIME.md` — текущее состояние контура, очередь и последние артефакты.

## Назначение системы
`POST` — модуль интеллектуальной переработки квалифицированных научных и технологических сигналов (преимущественно из дайджестов `MAYA`) в научно-популярные публикации для Telegram-канала.

* **Первичный источник истины:** локальный корень на хосте Архитектора (`/home/shaen/post`).
* **Публичный GitHub:** открытое зеркало для синхронизации контекста и бесшовного подключения LLM-агентов (обновляется строго после проверки и санкции Архитектора).

## Структура репозитория
* `README.md` — точка входа и протокол навигации для LLM.
* `CLAUDE.md` — оркестрация ролей и пошаговый пайплайн.
* `INVARIANTS.md` — жесткие ограничения и барьеры истинности.
* `EDITORIAL_POLICY.md` — голос канала, фильтр Первого эшелона и композиция.
* `RUNTIME.md` — живой статус, реестр материалов и открытые задачи.
* `templates/` — шаблоны карточек статей и логов.
* `records/` — архив проработанных материалов (`YYYY/NNN_<slug>.md`).
* `logs/` — append-only журналы событий, ревью и обратной связи.
* `scripts/` — задел под будущую полуавтоматизацию и CLI-утилиты.
