# POST — Контентный контур экосистемы NOVA CORTEX / MAIA

> **Для LLM-сессий:** точка входа — `00_ENTRY.md`. Этот README — для человека.

## Что такое POST
`POST` — автономный контентный конвейер экосистемы Nova Cortex (ядро `MAIA`). Преобразует квалифицированные сигналы из дайджестов `MAIA` в научно-популярные публикации для канала `@t_cortex` и зеркальных площадок. Модель дистрибуции — **Hub & Spoke** («2 языка × 2 скорости»).

## Три роли
- **Архитектор** — человек: стратегия, санкции, `git push`.
- **Редактор** — `Gate 1–3`: триаж, фактчекинг, пост, обложка 3:4, `Micro-Payload`.
- **Архиватор** — `Gate 4`: приём `Micro-Payload`, ведение репозитория, инварианты, Git.

## Структура репозитория
- `00_ENTRY.md` — единая точка входа для LLM.
- `INVARIANTS.md` — инварианты I1–I12.
- `CURRENT_STATE.md` — текущее состояние контура, реестр карточек.
- `DECISIONS.md` — архитектурные решения (ADR).
- `EDITORIAL_POLICY.md` — редакционный стандарт и триаж.
- `meta/` — правила LLM (`agent-rules.md`), профили ролей (`roles/`), handoff-протокол.
- `templates/record-template.md` — ультратонкий шаблон карточки.
- `records/YYYY/` — карточки (`NNN_<slug>.md`).
- `logs/` — append-only журнал (`events.jsonl`).
- `docs/` — матрица Hub & Spoke и справочник площадок.
- `scripts/precommit-checks.sh` — гейт I1+I4.
- `archive/` — устаревшие документы (для истории).
