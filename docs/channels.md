# POST — Справочник площадок (активные каналы)

Форматы, лимиты и правила оформления по каждой площадке Hub & Spoke.
Канонический источник — всегда `records/`.

---

## Telegram `@t_cortex` (RU · Атом)
- Лимит: 850–1 024 знака с пробелами (включая заголовок, эмодзи, ссылки).
- Обложка: 3:4 (единая для всех площадок).
- Формат: короткие абзацы, эмодзи-навигация, активные ссылки в конце.
- Публикация только после статуса `APPROVED` от Архитектора (I11).

## Хабр (RU · Сборка)
- Формат: обзор 3–4 карточек одного тематического кластера.
- Обложки 3:4 из карточек + обложка-обзор при необходимости.
- Лимит по объёму: обзор без жёсткого лимита, но без академического занудства (I10).
- Ссылки на канонические карточки в `records/` обязательны.

---
## Substack Notes (EN · Атом)
- Лимит: 800–1 000 знаков с пробелами.
- Обложка: 3:4.
- Ссылки активные, на каноническую карточку или arXiv/GitHub.

## Bluesky (EN · Атом)
- Формат: тред 3×300 графем.
- Ссылки без пессимизации (не скрывать в конце, не убирать превью).
- Обложка: первый пост треда = 3:4.

## Substack Newsletter (EN · Сборка)
- Формат: англоязычный обзор-дайджест по тематическому кластеру.
- Обложка: 3:4 (своя обложка-обзор).
- Ссылки на канонические карточки обязательны.

## Reddit (EN · Точечно)
- Сабредиты: `r/LocalLLaMA`, `r/AIAgents`.
- Условие: только под сильный GitHub-код или воспроизводимый результат.
- Формат: короткий пост + ссылка на карточку; без рекламного тона.

---

## Общие правила
- Единый источник — `records/`; производные форматы не противоречат карточке.
- Барьер истинности (I7) сохраняется во всех форматах: факты не подменяются интерпретациями.
- Публикация — только по статусу `APPROVED` (I11).
- Обложки 3:4 генерируются после 2-шагового согласования концепта.
