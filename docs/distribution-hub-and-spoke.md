# POST — Hub & Spoke: матрица дистрибуции «2 языка × 2 скорости»

Целевая архитектура распространения POST в Nova Cortex (ядро MAIA).
Каноническая карточка в центре, производные форматы — на периферии.

---

## Hub — центр
- Каноническая карточка: `records/2026/NNN_*.md`.
- Обложка 3:4 (единая для всех площадок).
- Единственный источник истины для всех производных форматов.

---

## RU · Атомы — Telegram `@t_cortex`
- Формат: 850–1 024 знака + обложка 3:4.
- Ритм: по мере готовности карточки (1 пост = 1 статья).
- Детали — в `docs/channels.md`.

## RU · Сборки — Хабр
- Формат: обзор 3–4 карточек одного тематического кластера.
- Обложки 3:4 из карточек + своя обложка-обзор (при необходимости).
- Ритм: ниже, чем атомы (1 сборка на 3–4 атома).

---
## EN · Атомы — Substack Notes + Bluesky
- Substack Notes: 800–1 000 знаков + обложка 3:4.
- Bluesky: тред 3×300 графем, без пессимизации ссылок.
- Ритм: синхронно с RU-атоми (1 карточка = 1 Notes + 1 тред).

## EN · Сборки — Substack Newsletter
- Формат: англоязычный обзор-дайджест по кластеру карточек.
- Ритм: ниже Notes (по мере накопления тематического кластера).

---

## Связь с порталом
