# POST — Agent Rules (общие правила для любой LLM)

## Ноль галлюцинаций
- Не додумывать по абстракту или заголовку. Любое утверждение — либо со ссылкой на первоисточник, либо помечено `[UNKNOWN]`.
- Все ключевые тезисы маркируются `[FACT]` / `[HYPOTHESIS]` / `[UNKNOWN]` (I7).

## Стоп-кран при блокировке доступа
- Если `arXiv` недоступен: **запрещён переход в `Gate 3`**. Зафиксировать пробелы `[UNKNOWN]` и выдать готовый шаблон запроса для соседней LLM с доступом к сети.

## Пошаговая работа
- Не смешивать стадии (`Gate 1` / `Gate 2` / `Gate 3` / `Gate 4`).
- Один цикл = один артефакт на выходе (`Micro-Payload` от Редактора, коммит от Архиватора).

## Минимализм (I12)
- Не дублировать полные тексты постов, пересказы статей, описания/файлы обложек в Git.
- Источники истины — БД `MAIA` и площадки публикации.
