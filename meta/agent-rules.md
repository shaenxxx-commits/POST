# POST — Agent Rules (общие правила для любой LLM)

## Нумерация ответов
- Формат: `MS N` — отдельной первой строкой ответа, ничем не предваряется.
- Один номер на один полный ответ. Сквозная нумерация внутри чата, начинается с 1.
- Внутри блоков кода и команд номер не ставится.

## Даты
- Допустимые источники даты: свежий вывод `date -u` в терминале, метаданные входного дайджеста `MAIA` или явный ввод Архитектора.
- Запрещено брать дату из памяти или предположений. Если дата не получена — ставить `[ДАТА НЕ ЗАФИКСИРОВАНА]` или не создавать документ.

## Формат правок документов
- Нормативные (изменяемые) документы выдаются целиком, одним блоком.
- Для append-only файлов (`DECISIONS.md`, `logs/events.jsonl`, `records/`) допускается только фрагмент «добавить в конец».
- Любая правка выполняется только по явной санкции Архитектора.

## Иерархия источников истины (I5)
При конфликте данных приоритет от высшего к низшему:
1. Текущий ввод Архитектора.
2. Свежий терминальный вывод текущей сессии.
3. Содержимое репозитория по конкретному SHA.
4. Документация проекта (`INVARIANTS.md`, `CURRENT_STATE.md`, `DECISIONS.md`, `meta/`).
5. Handoff-пакеты и сводки предыдущих чатов.
6. Память агента (не используется для утверждения фактов).

## Запрет реконструкции и ноль галлюцинаций (I7)
- Реконструкция утраченного сырья по памяти или пересказу запрещена.
- Не додумывать по абстракту или заголовку. Допустимы только запрос через внешнюю разведку или явная фиксация `[UNKNOWN]`.
- Все ключевые тезисы маркируются `[FACT]` / `[HYPOTHESIS]` / `[UNKNOWN]`.

## Делегирование внешней разведки
- Если у модели нет прямого доступа к веб-поиску или полному тексту статьи, черновой поиск и первичный сбор фактуры делегируются внешним поисковым нейросетям через компактный запрос, который Редактор передаёт Архитектору на прогон в чистом поисковом чате.
- Ответ внешней нейросети не принимается на веру: он проходит проверку через барьер истинности (`I5`, `I7`) перед использованием.

## Пошаговая работа
- Не смешивать стадии (`Gate 1` / `Gate 2` / `Gate 3` / `Gate 4`).
- Один цикл = один артефакт на выходе (`Micro-Payload` от Редактора, коммит от Архиватора).

## Минимализм (I12)
- Не дублировать полные тексты постов, пересказы статей, описания/файлы обложек в Git.
- Источники истины — БД `MAIA` и площадки публикации.
