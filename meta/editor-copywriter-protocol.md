# POST — конвейер Редактор → Копирайтер

**Версия: 1, 2026-11-22**
Статус: рабочее соглашение, не инвариант.
Основание: пробный проход дайджеста 2026-11-19, maia_id 484476.

## Роли
- **Архитектор (человек):** дайджест с хоста, перенос оригинала, выбор обложки, `APPROVED`, санкция на Git.
- **Чат «Редактор»:** триаж, чтение оригинала, запертые факты, английский каркас, три темы обложки. Постов по-русски и картинок не делает.
- **Чат «Копирайтер»:** русский пост и обложка. Новых утверждений не добавляет.
- **Архиватор:** приём пакета в репозиторий. Не этот протокол сам по себе.

## Вход
Read-only: `bash scripts/get-digest.sh YYYY-MM-DD`
Сырьё одной карточки: тот же скрипт с `--ids`.
MAIA не меняется: ни схема, ни workflow, ни записи.

## Gate 1
Шорт-лист по действующему правилу `score > 8`.
Рядом с каждым `score` — версия оценщика MAIA.
У каждой строки — ссылка на источник.
`TRIAGE_LOG` по всем 15 позициям: `maia_id`, `selected | reserve | rejected`, код причины.
Код, проект и видео — не из подсказок OpenAlex, только если ссылка найдена в статье.

## Gate 2
Одна статья за пакет. Полный текст в чат Редактора не копируется.
Факты, цифры, черновик и темы обложек — на английском.
По-русски только служебная строка.

## Пакет
- служебная строка: дата, номер в шорт-листе, `maia_id`, `score`, `scorer`, `kind`
- ссылки: html, pdf, abs, код
- `[FACT]` / `[HYPOTHESIS]` / `[UNKNOWN]`
- `DO NOT CLAIM`
- технический черновик (каркас, стиль не сохранять)
- три равноправные темы обложки, без картинки и без выбора «лучшей»
- запрет копирайтеру заполнять дыры

Оригинал в чат «Копирайтер» прикладывает Архитектор.
Перевод делает Копирайтер.

## Возврат
Русский пост возвращается Редактору. Проверка только чисел, имён и причинности. Стиль не правится.
Обложка в этот возврат не входит.

## Чего протокол не решает
- где хранить тексты постов при `POST.I12` (публичный Git их не содержит; отдельный приватный архив — открытый вопрос);
- калибровку порога `score` (`TRIAGE_LOG` для этого копится, порог пока прежний);
- запись протокола в Git и префиксы `POST.I*` / `MAIA.I*` — отдельные задачи Архиватора.
