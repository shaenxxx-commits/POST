# POST — Handoff Protocol (два пакета)

Схемы двух пакетов конвейера. Содержимое пакетов (тексты постов, обложки) в Git **не хранится** (`I12`). В Git — только поля.

## Пакет 1: Редактор → Копирайтер (в чате, не в Git)

Передаётся вместе с оригиналом статьи от Архитектора. Язык фактов и черновика — **английский** (перевод — задача Копирайтера). Копирайтер возвращает русский пост + обложку.

Поля:
- **служебная строка:** digest_date, shortlist_pos, maia_id, score, scorer, kind
- **links:** arxiv_abs, arxiv_pdf, arxiv_html, code_or_data
- **claims:** 3–5 буллитов `[FACT]` / `[HYPOTHESIS]` / `[UNKNOWN]`
- **do_not_claim:** список запрещённых утверждений
- **tech_draft:** английский черновик (стиль не сохранять, только каркас)
- **cover_themes:** три равноправные темы (без картинки, без выбора «лучшей»)

Правила:
- Редактор **не пишет** русский пост и не генерирует картинки.
- Копирайтер **не ищет** и не добавляет фактов вне `claims`; дыры не заполняет; `do_not_claim` соблюдает.
- Обложки в Git не попадают: ни файлы, ни пути, ни описания.

---

## Пакет 2: Редактор → Архиватор (Micro-Payload)

Эталонный шаблон для фиксации карточки в репозитории. `I12`: без текстов постов, без пересказов, без обложек.

Поля:
- **record_id:** 2026-NNN
- **digest_ref:**
  - date: YYYY-MM-DD
  - digest_pos: #N
  - maia_id: <incoming_messages.id>
  - score: X
  - scorer: <версия оценщика MAIA или "—">
  - kind: <payload.kind из digest_log>
  - shortlist_pos: M
- **title:** <Оригинальное название>
- **authors_org:** <Авторы> (<Организация>)
- **cluster:** <Тематический кластер>
- **artifact_tier:** A | B | C
- **code_status:** open | closed | not_reported
- **links:**
  - arxiv: https://arxiv.org/abs/XXXX.XXXXX
  - code_or_data: <URL или "—">
  - project_page: <URL или "—">
  - video: <URL или "—">
- **claims:** 3–5 буллитов `[FACT]` / `[HYPOTHESIS]` / `[UNKNOWN]` на английском (не переводить — риск искажения по I7)
- **published:**
  - tg: https://t.me/t_cortex/<post_id>
  - date: YYYY-MM-DD

## Правила валидации

### Micro-Payload (Пакет 2)
- Все поля обязательны; пустые — явный "—".
- `maia_id` — положительное целое из `incoming_messages.id`.
- `record_id` уникален, `2026-NNN` сквозной (I2).
- `claims` — 3–5 буллитов суммарно, на английском.
- При нарушении — вернуть Редактору на доработку, не создавать карточку.

### Пакет 1 (в чате)
- Проверка Архиватором не выполняется (пакет не в Git).
- Ответственность за целостность — Архитектор и Копирайтер.
